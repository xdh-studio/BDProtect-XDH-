# 批量特征上传程序

把某个文件夹里所有文件的**特征（文件名、大小、MD5）**批量写入云端病毒库 `Wildlist.txt`，
上传前会与云端病毒库对比，自动跳过重复项。

## 使用

1. 确认 `IPconfig.ini` 与本程序在同一目录，内容例如：

   ```
   server_ip=152.136.44.200
   server_port=28586
   ```

2. 双击 `BatchUpload.exe`，输入管理密码（与 BDAdmin 相同，服务器 `data/admin_password.txt`）。
3. 点击「浏览...」选择文件夹，按需勾选「包含子文件夹」。
4. 点击「扫描文件夹」：
   - 程序先读取云端 `Wildlist.txt`，再逐个计算本地文件的 MD5；
   - 列表中会标注每一行状态：
     | 状态 | 含义 |
     | --- | --- |
     | 新增 | 云端没有这个 MD5，可以上传 |
     | 新增（云端有同大小条目） | MD5 不同，但云端有一条同大小的记录 |
     | 重复：云端已有 | 云端已有相同 MD5，不会重复上传 |
     | 重复：本文件夹内已有 | 同一文件夹里有多个相同文件，只传第一个 |
5. 点击「上传新增特征」，确认后逐条写入云端病毒库：
   - 先用现有命令 `addvirus <大小> "<名称>"` 追加条目，
   - 再用 `editvirus <大小> "<名称>" <大小> "<名称>" "<MD5>"` 给同一行补上 MD5。
   - **不需要修改或重新部署 `server.php`**，使用的都是服务器已有命令。
   - 上传完成后会重新读取 `Wildlist.txt` 核对每个 MD5 是否真的写入。
6. 默认勾选「上传后自动发布新病毒库版本」：上传成功后把 `WildlistVersion.txt` 版本号升一位，
   客户端下次启动才会自动拉取新病毒库；不勾选则需要到管理程序里手动「发布新的病毒库」。

## 说明

- 病毒名默认取文件名（去掉扩展名），空格/引号会替换为下划线；
  与云端或本批其它文件“同大小同名”时自动加 `_2`、`_3` 后缀，避免服务器判重后误改旧条目。
- 0 字节文件会跳过；单个文件夹最多处理 20000 个文件。
- 每条约需 2 次请求（addvirus + editvirus），文件多时上传会花几分钟，界面有进度提示。
- 如果上传后提示“云端找不到对应 MD5”，说明服务器上的 `server.php` 过旧、`editvirus`
  不支持哈希参数，可从管理程序里核对病毒库内容。

## 编译

双击 `build.bat`（需要 MinGW-w64 的 gcc），或手动执行：

```
gcc -O2 -Wall -municode -mwindows BatchUpload.c -o BatchUpload.exe ^
    -luser32 -lshell32 -lgdi32 -lcomctl32 -lcomdlg32 -lws2_32 -lole32 -lbcrypt
```
